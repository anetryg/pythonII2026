# Programování v geoinformatice II
## Seznam kapitol
Každá kapitola obsahuje odkaz na odpovídající složku v tomto repozitáři
1. [ArcPy](./01-arcpy)
    * Python v ArcGIS Pro (Python window, Python Notebook, samostatné skripty, Python toolbox)
    * knihovna ArcPy a volání geoprocessingových nástrojů
    * modul arcpy.da (SearchCursor, UpdateCursor, InsertCursor)
    * modul arcpy.charts
    * modul arcpy.mp
    * Python CIM
2. [AI a testování](./02-ai_a_testovani)
    * způsoby, jak AI generuje kód, a kolik kontroly každý vyžaduje
    * kde a proč AI selhává
    * prompt jako specifikace
    * postup kontroly vygenerovaného kódu
    * assert a knihovna pytest
    * testy jako spustitelná specifikace
    * jednotkové, integrační a end to end testy
    * vývoj řízený specifikací (spec-driven development)
3. [Open source knihovny](./03-open_source)
    * Shapely: geometrie, operace a prostorové vztahy
    * GeoPandas: atributová tabulka, souřadnicové systémy, prostorové spojení a překryv
    * rasterio: metadata, pásmová matematika a ořez rastru
